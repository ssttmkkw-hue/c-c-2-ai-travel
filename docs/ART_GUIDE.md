# 美术风格规范

**一句话**：低多边形几何体 + 3 阶卡通阴影 + 深色描边，渲染后像素化（默认内部分辨率短边约 400~540，设置里可调）。
像素化会吃掉细节，所以**造型要大、轮廓要清楚、颜色块要分明**，不要做小细节。

## 1. 尺寸（单位：米）

| 物体 | 尺寸 |
|---|---|
| 玩家角色（Q 版） | 身高 ≈ 1.2，头身比约 1:1.2（大头） |
| 门 | 高 1.6~2.0 |
| 普通楼层 | 层高 3 |
| 路灯 | 3~4 |
| 树 | 3~6 |
| 地标（鸟居/金字塔/铁塔） | 可以夸张，但要在出生点就能看到 |
| 地图可走范围 | 约 90m × 90m（`halfSize` 45） |

建筑可以比现实「矮胖」一点，Q 版世界更可爱，也减少遮挡。

## 2. 面数 & 构造

- 只用 `@/art/kit` 的基础件拼：`box` `cylinder` `cone` `ball` `group` `place`
- 圆柱 / 圆锥分段数：小物体 6，中物体 8，大物体最多 12
- `ball` 默认 detail 0（二十面体），树冠就用它，最多 detail 1
- 单个道具 ≤ 15 个部件；单个建筑 ≤ 40 个部件
- 部件之间可以穿插重叠，不必精确拼接（看不出来）
- 道具/建筑的正面（门、窗、招牌）朝 **+Z**；可以用 `obj.lookAt(x, 0, z)` 让正面对着某点
- 人字屋顶、帐篷用 `kit.prism`（三棱柱）

## 3. 颜色

- 场景主体颜色**只从调色板取**：`p.primary` 建筑、`p.accent` 点缀、`p.foliage` 植被、`p.ground` 地面
- 用 `pick(p.primary, i)` 循环取色，同类物体相邻时错开颜色
- 「现实中就是这个颜色」的东西（皮肤、木头、石头）用 `src/art/colors.ts`
- 发光物体（霓虹、灯笼、窗户夜景）用 `emissive` 参数，`emissiveIntensity` 0.5~1
- 同一画面中饱和色占比 < 20%，大面积用低饱和色，点缀色才鲜艳

### 调色板设计方法（新地图卡）

1. 先定**时间 + 氛围**：东京 = 黄昏樱花，吉萨 = 正午烈日，巴黎 = 清晨薄雾…
2. `sky` / `fog` 决定整体色调，二者相近
3. `primary` 3~5 个：从浅到深，同一色相附近
4. `accent` 2~4 个：与 primary 形成对比（互补色或高饱和）
5. `outline` 用深色同色系（不是纯黑）：暖色场景用深棕紫，冷色场景用深蓝
6. 调完在游戏里看：像素颗粒「标准」档下轮廓和层次是否清楚

## 4. 描边

- 默认所有部件 `outline: true`
- **关闭描边**：地面、路面、贴在墙上的薄片（招牌、窗户）、小于 0.3m 的小物件、半透明物体
- 描边在屏幕上恒为 1 个像素宽（像素风），和物体远近、大小无关。所以：
  - 比 1 个像素还细的东西（电线、细绳）**要开描边**，否则远看会断成虚线
  - 物体不要悬空几厘米：底下那圈很细的影子会变成一排虚线，直接落地（y=0）

## 5. 阴影

- 默认投射阴影。地面和贴地薄片 `shadow: false`
- 太阳方向固定在 (30, 50, 20)，地图布局时让地标的受光面朝向出生点会更好看

- [ ] 第一人称和第三人称视角都没有穿模 / 巨大遮挡
- [ ] 从出生点能看到地标
- [ ] 没有在模型代码里写死颜色（固有色除外）
- [ ] 地图切进切出 10 次没有明显卡顿（控制台 `__game.engine.renderer.info` 看 geometries 数量不增长）
