# 地图卡制作规范

一张地图卡 = 一个城市/景点的**小场景**（约 90m × 90m），重点是“一眼认出来是哪里”。

## 文件结构

```
src/maps/<id>/
├── index.ts      MapCardDef（基本信息 + npcs + build）
├── palette.ts    调色板
└── *.ts          （可选）本地图专属模型，如 landmark.ts、layout.ts
```

从 `src/maps/_template/` 复制开始，完成后在 `src/world/registry.ts` 注册。

## 场景构成（每张卡都要有）

1. **地标**（1 个，必须）：最能代表这个地方的东西，放在出生点正前方远处，出生时就能看到
2. **街景 / 环境**（主体）：2~3 种建筑或自然元素重复 + 变化，营造“当地感”
3. **路径**：一条从出生点通往地标的路，引导玩家走过去
4. **点缀**：当地特色小物（自动售货机、咖啡桌、骆驼、船…）
5. **NPC**（≥ 1）：至少一个导游 NPC，站在出生点附近，`lines` 写 2~4 句欢迎和介绍
6. **边界**：地图边缘用建筑 / 山 / 树林 / 水自然围住，配合雾让玩家看不到“世界尽头”
7. **当地服装**：在 `src/avatar/outfits.ts` 加至少 1 套，`origin` = 地图 id

## 布局建议

```
            [ 边界：建筑/山/树 ]
     ┌──────────────────────────────┐
     │            ★ 地标             │  z = -30 附近
     │             ║                │
     │   建筑      ║ 路径     建筑   │
     │   点缀      ║          点缀   │
     │             ║  NPC           │
     │             ● 出生点          │  z = +20 附近，yaw 0 朝 -Z 看向地标
     └──────────────────────────────┘
```

## 代码约定

- 用 `ctx.add(obj, { collide: true })` 添加大物体（建筑、墙、地标），玩家走不进去
- 小装饰（< 1m）不加碰撞
- 随机布局只用 `ctx.rand()`（可复现），不要用 `Math.random()`
- 动画（旋转、飘动）用 `ctx.onUpdate((dt, t) => ...)`，卸载时自动清理
- **会动的物体创建时用 `kit.dynamic(obj)` 标记**（每帧改位置 / 旋转 / 缩放 / visible 的那个节点）。
  地图建好后不动的零件会被自动合并成几个大 mesh（静态合批，见 `src/render/batch.ts`），没标的物体动画不会生效
- 大量重复的小东西（草、石子）用 `kit.instances(...)` 或 `addGroundDetail(ctx, ...)`（`@/art/props`）；飘落粒子用 `addFallingParticles`（`@/fx/particles`）
- 不要往 `engine.scene` 直接加东西，不要持有地图外的引用
